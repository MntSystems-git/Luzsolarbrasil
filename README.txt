LUZ SOLAR BRASIL - LANDING PAGE

Arquivos:
- index.html
- style.css
- script.js
- assets/

Como usar:
1. Envie a pasta inteira para sua hospedagem.
2. Abra index.html.
3. O formulário salva uma cópia dos leads no localStorage do navegador e abre o WhatsApp (75) 98305-6912 com os dados preenchidos.

IMPORTANTE PARA CAPTAÇÃO PROFISSIONAL:
Para centralizar leads em CRM, planilha ou banco de dados, substitua/adapte a rotina de submit do arquivo script.js para enviar os dados via fetch() para seu webhook/API (ex.: Make, n8n, RD Station, Kommo, HubSpot ou backend próprio). Não exponha tokens secretos no JavaScript do navegador.

Conteúdo visual e textual inspirado no material institucional fornecido da Luz Solar Brasil, com identidade azul, amarela e branca.
